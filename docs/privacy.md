# Privacy Policy

_Last updated: November 26, 2026_

Shorts Factory is a personal automation tool operated by the owner of the Kinetic Lab and Clear Mechanics
YouTube channels. It is not offered to the public and only the owner signs in.

## Data accessed
Through the YouTube Data API (scopes `youtube.upload` and `youtube.force-ssl`) the tool accesses only the owner's
own channels in order to upload videos, read public comments on the owner's own videos, post replies to those comments,
and manage the owner's own playlists.

## Data stored
The tool stores only video IDs, publish timestamps and the IDs of comments it has already replied to, so that it never
replies twice. It does not store comment authors' personal information, and it does not sell, share or transfer any data
to third parties.

## Google API Services User Data Policy
Shorts Factory's use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements. YouTube data is handled in accordance with the
[YouTube Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).

## Revoking access
The owner can revoke the tool's access at any time at
[https://myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## Contact
Questions can be sent through the "About" page of the Kinetic Lab or Clear Mechanics YouTube channels.
