# Shorts Factory

Shorts Factory is a personal, non-commercial tool that publishes original animated science and physics
short videos to the creator's own YouTube channels (**Kinetic Lab** and **Clear Mechanics**) and Instagram accounts.

It uses the YouTube Data API only to:

- upload videos to the creator's own channels,
- read and reply to comments on the creator's own videos,
- organize the creator's own videos into playlists.

The tool is used only by its owner. It does not offer sign-in to other users.
